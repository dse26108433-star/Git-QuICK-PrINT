Checking Microsoft Word on this PC…

Students add Word files like any other file. This PC opens each one in its own Microsoft Word, out of sight, and turns it into pages: it prints exactly as it would from a pen drive, and the student sees those pages before paying. A file with macros or anything else that can run is refused before it gets here. The Word you work with yourself is not touched.

Installing takes a minute

Android asks a few questions for every app that does not come from the Play Store. That is normal: XeoGo is the Xerox center's own app.

  1. The download starts by itself (if not, tap Download for Android). If Chrome asks whether to keep the file ("File might be harmful"), tap Download anyway.
  2. When it has downloaded, tap Open. (Missed it? Chrome menu ⋮ → Downloads → XeoGo.apk.)
  3. If your phone asks, allow Chrome to install apps: Settings → switch on Allow from this source → go back.
  4. Tap Install. If Play Protect says it does not know this app, tap More details → Install anyway (or Scan app, then Install).
  5. Had XeoGo before? If it says "App not installed", uninstall the old XeoGo first (press and hold its icon → Uninstall), then install again. Your orders are kept by the Xerox center.

Rather not install anything?

The website does everything the app does, right here in Chrome. iPhone users: use this.

Use XeoGo in the browser

Tip: in Chrome tap ⋮ → Add to Home screen, and it opens like an app.

What the app can do on your phone

  • Use the internet, to send your files to the Xerox center
  • See which UPI apps you have, to let you pay with one
  • Nothing else: no SMS, contacts, photos library, location, camera or microphone
  • No account needed, no ads; your files are deleted after printing (privacy)
